# Introduction <a name="introduction"></a>

Meta published the foundational LLaMA model [paper](https://arxiv.org/pdf/2302.13971.pdf) on 2023-02-27. Followed by LLaMA-2 [paper](https://arxiv.org/pdf/2307.09288.pdf) on 2023-07-19. And most recently, LLaMA-3 [repo](https://github.com/meta-llama/llama3/blob/main/MODEL_CARD.md) on 2024-04-18.

Since LLaMA-3 doesn't yet come with an arxiv paper, we're going to study LLaMA-2's architecture. It was noted that the key changes from 2 to 3 are
1. vocab size from 32k to 128k, and
2. using Grouped Query Attention (GQA) (but LLaMA-2's paper mentions the use of GQA already, so it's unclear at first glance what differs)

Our main goal is to understand LLaMA's architecture design.

Note that the parameters are not exact, some of the info is pulled from Karpathy's llama.c model, for instance, the `hidden_size` ends up being shown as 288 instead of 4096. For accurate llama 2 parameters, consult hugging face [model card](https://huggingface.co/docs/transformers/main/en/model_doc/llama2#transformers.LlamaConfig). ### tok_embeddings

An input prompt "Where is the dog?" gets tokenized using Byte-Pair encoding to a series of tokens  

```python
from sentencepiece import SentencePieceProcessor
sp_model = SentencePieceProcessor("tokenizer.model")
sp_model.encode("Where is the dog?")

>>>> [6804, 338, 278, 11203, 29973]
```

LLaMa 1 and 2 has vocab size of 32k, thus the embedding step is a table of 32k entries that projects each token into a vector of size "hidden size", which in this case is 288. Thus we see 
`tok_embeddings.weight: torch.Size([32000, 288])`

Thus after the embedding stage, the output shape becomes `input_len x hidden_size`

### Transformer

The transformer is composed of 6 attention blocks, where each block takes in a tensor of `input_len x hidden_size`.

Each of the `input_len x hidden_size` input is multipled by three weight matrices of shape `hidden_size x hidden_size` into three matrices known as K, Q, V for (Key, Query, and Value respectively)
